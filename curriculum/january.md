# January — Rep 4 + outreach

~12 hours of Rep 4, run **alongside** outreach, not before it.

Three experiments against systems you already built. Each ends as a one-pager in
`patterns/` answering a question clients actually ask.

**MCP (~4h)** — "Can this plug into our systems?"
Repackage Rep 2's tools as an MCP server. The load-bearing one of the three.

**Multi-agent (~4h)** — "Shouldn't this be a team of agents?"
Split Rep 2 into orchestrator + specialists. Run against the eval harness you already
have. Expect slower, pricier, no more accurate. That measured result is the deliverable.

**Fine-tuning (~4h)** — "Should we train our own model?"
Fine-tune a small model on Rep 1's labeled set. Compare to the prompted baseline on
accuracy, cost, latency. The skill is knowing the narrow case where it wins.

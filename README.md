# FDE Gym

Training repo: machine learning engineer -> forward deployed engineer, solo consulting.

**Oct** Can I build it? · **Nov** Should I build it? · **Dec** Can I find that out with a customer? · **Jan** Real outreach.

~7 hrs/week. Stack: Python, GCP (Vertex AI, Cloud Run, BigQuery, GCS), Claude API.

## The pattern

Every October rep builds the same thing end to end:

> messy input -> structured extraction -> human review -> write to system of record -> eval harness that proves it works
